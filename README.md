# MenoRadio

MenoRadio 是一款面向 Windows 的第三方网易云音乐播放器，专注于简洁的音乐浏览、播放队列与歌词体验。它提供与 LyricEase 相似的沉浸式播放页，并支持同步歌词与翻译、悬浮歌词、歌单管理、搜索、推荐与私人漫游等功能。

可通过扫码、账号密码或 Cookie 登录网易云音乐；歌曲及账号功能的可用范围以网易云音乐当前提供的服务和账号权限为准。
